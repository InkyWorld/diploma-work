# 1. Процес переходу користувача за посиланням

Головна сторінка: Welcome сторінка. Загальний опис системи, зображення на фоні та кнопка для реєстрації/входу.

- Вхід: Користувач вводить свої дані для входу (логін, пароль) або реєструється на сайті.
- Перевірка ролі: Після входу система перевіряє роль користувача і перенаправляє його на відповідну панель управління.
- Реалізація маршрутизації: Використовуючи React Router, кожна роль має свою сторінку, на яку вона потрапляє після входу:

/admin для адміністратора
/engineer для інженера
/foreman для бригадира
/worker для робітника
/dispatcher для диспетчера

2. Інтерфейс та функціонал для кожної ролі

# Адміністратор

Головна панель (Dashboard): Панель з основними метриками (кількість користувачів, активні завдання, статус системи).

- Управління акаунтами: Адміністратор може створювати нових користувачів, редагувати їх інформацію, видаляти акаунти.
- Перегляд звітів та даних: Виведення статистики по всіх задачах і користувачах системи (наприклад, кількість виконаних завдань, статуси робіт).

# Інженер

Головна панель (Dashboard): Виведення актуальних пакетів робіт, що потребують уваги.

- Перегляд пакетів робіт: Сторінка з усіма доступними для перегляду та роботи пакетами завдань.

# Бригадир

Головна панель (Dashboard): Виведення списку працівників, їх статусу та поточних завдань.

- Призначення завдань: Бригадир призначає конкретні завдання робітникам.
- Перевірка прогресу: Можливість перевіряти статус виконання завдань, взаємодіяти з робітниками через систему комунікацій.

# Робітник

Головна панель (Dashboard): Робітник бачить всі завдання, що призначені йому.

- Перегляд завдань: Список завдань з деталями про роботу, що потрібно виконати.
- Виконання завдання: Можливість позначити завдання як виконане, додавати коментарі або при необхідності вказувати на проблему.
- Прогрес виконання: Виведення прогресу по завершеним завданням, доступ до аналітики за результатами роботи.

# Диспетчер

Головна панель (Dashboard): Панель з поточними рейсами та їхнім станом.

- Перегляд рейсів: Диспетчер може переглядати всі рейси, які є в системі, зі статусами обслуговування літаків.
- Фільтрація рейсів: Можливість фільтрувати рейси по датах, типах літаків, статусах технічного обслуговування.
- Деталі рейсу: Виведення детальної інформації по кожному рейсу (наприклад, коли був останній ремонт, чи потребує літак технічного обслуговування).

3. Перехід між ролями і функціоналом
   Системи прав доступу: Завдяки JWT і авторизації користувачі можуть потрапити лише на ті сторінки, які відповідають їхній ролі.
   Налаштування безпеки: Для кожної ролі будуть обмеження, щоб доступ був лише до необхідних розділів

4. Повний процес взаємодії користувача
   Користувач заходить на сайт і вибирає свою роль.

Вводить логін,пароль,вибирає свою роль для входу.

Після входу система перенаправляє його на відповідну панель управління.

Користувач виконує необхідні дії:

Адміністратор керує акаунтами, даними.
Інженер переглядає пакети робіт.
Бригадир призначає завдання та контролює виконання.
Робітник відмічає виконані завдання.
Диспетчер перевіряє рейси та їх стан.

Завершивши дії, користувач може вийти із системи або перейти на головну сторінку

5. Допоміжний функціонал
   Пошук та фільтрація: Для швидкого доступу до потрібної інформації (наприклад, пошук по пакетах робіт або рейсах).
   Сповіщення: Користувачі можуть отримувати сповіщення про важливі зміни, призначення нових завдань чи зміни статусу.
